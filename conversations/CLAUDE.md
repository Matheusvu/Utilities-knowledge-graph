# conversations/ — recorded + distilled session memory

The compounding loop (PLAN §3.4). Each analysis session is recorded here as a dated, tagged record (question, findings, sources, conclusions) so the system learns from use.

- **Auto-record:** a `Stop` hook writes a session record here (Phase 7).
- **Promote:** `/log-insight` distills a finding into the durable knowledge base when it's worth keeping.

**Compliance:** persist analytical conclusions and public-source facts — **not** sensitive/MNPI deal data — unless explicitly directed.
